# Data Directory

This directory contains the dataset used for cardiovascular disease prediction.

## Dataset

**Source:** [Kaggle - Cardiovascular Disease Dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset)

**File:** `cardio_train.csv`

### How to Get the Data

1. Visit the Kaggle dataset page
2. Download `cardio_train.csv`
3. Place it in this directory

### Dataset Description

- **Records:** ~70,000 patient records
- **Features:** 12 features including age, gender, blood pressure, cholesterol, etc.
- **Target:** Binary classification (presence of cardiovascular disease)

**Note:** The actual data file is not tracked in Git.
